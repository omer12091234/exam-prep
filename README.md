## הרצת הדוגמה (מקומית, בלי Supabase ובלי Docker)

צריך Node.js 22 (מומלץ) או לפחות 20.19 – גרסאות 20 ישנות יותר לא יעבדו עם Prisma.

```bash
cp .env.example .env
npm install
npm run demo
```

`npm run demo` מפעיל Postgres מקומי (`prisma dev`, פורט 51214), מריץ migrations,
טוען שלושה קורסים (164 מבחנים, כולל מבחן 2023 מועד א' עם חיתוכים והערות בודק)
ומפעיל את האתר ב-http://localhost:3000.

כשאין `NEXT_PUBLIC_SUPABASE_URL` ב-`.env` האתר רץ במצב דמו: אין התחברות, ויש משתמש אדמין מקומי אחד.

פקודות נוספות:

| פקודה | מה עושה |
|---|---|
| `npm run db:start` / `npm run db:stop` | הפעלה / עצירה של ה-Postgres המקומי |
| `npm run db:setup` | migrations + seed + ייבוא הקורסים (בטוח להריץ שוב) |
| `npm run db:import` | רק ייבוא הקורסים מ-`data/study` |
| `npm run dev` | רק האתר, כשה-DB כבר רץ |

## מה יש באתר

- **קורסים**: כל משתמש בוחר את הקורסים שלו אחרי ההרשמה, ומוסיף או מסיר בעמוד ההגדרות. מנהל משנה קורסים ותפקידים לכל משתמש ב-`/admin/users`.
- **תרגול לפי מבחן או לפי נושא**: לכל סעיף סטטוס (לא נפתר / הצלחתי / התקשיתי / לא הצלחתי). בדף נושא: סיכום, נוסחאות, טעויות נפוצות וכל הסעיפים ממבחני העבר בנושא, ממוינים לפי קושי.
- **התקדמות לכל קורס**: כמה מבחנים וכמה שאלות בוצעו ונשארו.
- **טיימרים**: ספירה לאחור למבחן שלם (נשמרת בשרת) וסטופר לכל שאלה.
- **שליחה לבדיקה**: מעלים פתרון למבחן או לשאלה, והוא נבדק עם Claude לפי סקיל הבדיקה של הקורס (`data/grading/`). מתקבל דוח עם ניקוד, הערות, תיקונים וטיפים. דורש `ANTHROPIC_API_KEY`.

## הנתונים

`data/study/*.json` הם קובצי הקורסים המנותחים (נושאים, מבחנים מתויגים, שאלות תרגול, הרצאות מתורגמות).
`npm run db:import` טוען אותם למסד. הייבוא בטוח להרצה חוזרת ולא מוחק התקדמות של משתמשים; הוא רץ גם בכל deploy.

## דוגמת החיתוך

צריך Python 3 עם `pip install -r ingest/requirements.txt`.

```bash
python3 -I ingest/crop.py ingest/example/extraction.json ingest/example/pages out
```

התוצאה בתיקייה `out/`: חיתוך לכל סעיף ולגוף השאלה, `manifest.json` ותמונות `overlay_*.jpg` לבדיקה.
פרטים על תהליך הקליטה ב-[ingest/README.md](ingest/README.md).
